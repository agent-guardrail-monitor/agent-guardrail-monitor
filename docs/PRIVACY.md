# Política de Privacidade — O Guardião - W

Data de vigência: 23 de setembro de 2026

O Guardião - W usa apenas as informações necessárias para verificar as travas de segurança, mostrar o resultado das verificações e preparar um conserto quando essa função estiver habilitada.

## GitHub

O Guardião lê os arquivos necessários para verificar as travas de segurança.

Quando o conserto está habilitado, ele pode criar uma alteração separada no GitHub para que a equipe revise antes de colocar no sistema principal.

O Guardião não cria uma base própria com o conteúdo dos repositórios dos clientes.

## Conserto

O Guardião tenta primeiro usar o último estado aprovado como referência.

Quando isso é suficiente, o conserto é preparado sem enviar o conteúdo para outro serviço de IA.

Se esse caminho não for suficiente e o apoio externo estiver habilitado, apenas o contexto necessário para entender a falha pode ser enviado ao serviço configurado para ajudar no conserto.

## Conexão com o GitHub

O Guardião usa a autorização do GitHub para confirmar que a pessoa pode conectar aquela conta e aqueles repositórios.

A autorização temporária usada nessa confirmação não é guardada depois que o processo termina.

## Dados operacionais

Os provedores usados para hospedar o serviço podem manter registros técnicos comuns de acesso, segurança e disponibilidade.

## Venda de dados

O Guardião - W não vende dados dos usuários.
